Right now, using AI still feels like an advantage. But what happens when everyone uses AI? The same models. The same tools. The same prompts.

Slop existed long before AI. Generic work has always existed. AI didn't create slop. It just made slop faster.

> If the tools are the same for everyone, then the differentiator was never the tool. It was always the person.

The desire path isn't towards becoming more like AI. It's towards becoming more recognisably human.

Perhaps the next shift in the AI era isn't learning how to use AI. It's learning how to make your use of AI unmistakably your own.
